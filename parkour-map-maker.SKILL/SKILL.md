# 像素跑酷地图制作

为本项目的 HTML5 像素跑酷游戏制作新关卡。地图是纯 ASCII 文本：加一张图 = 在 `src/levels/maps/` 新建一个 `.ts` 文件，不改任何其他代码（`import.meta.glob` 自动注册）。

## 前置阅读（按需）

- 项目根目录 = 当前会话的主项目目录（已打开的 Parkour-game）。
- 动手前先读：`src/core/map-format.ts`（字符表与解析器）、`src/core/config.ts`（手感参数）。
- 参考现有图：`src/levels/maps/01-tutorial.ts`（最简模板）。
- 校验脚本口径：`scripts/validate-maps.mjs`（结构）、`scripts/simulate.mjs`（可通关性）。

## 工作流

1. **明确需求**：主题（forest/cave/sky，写进 `meta.theme`）、要使用的机关（尖刺/岩浆/弹跳板/移动平台/加速带/金币/检查点）、难度目标、大概画布尺寸。
2. **确定文件名与 id**：文件名前缀决定选关顺序，用两位数字编号（`04-my-level.ts`）；`meta.id` 全局唯一（存档 key），不要与现有图重复。先 `Get-ChildItem src/levels/maps` 确认下一个编号与已有 id。
3. **设计网格**：在草稿上按"逐行字符串"绘制，遵守下面的物理约束与硬性规则。每行长度可以不同，解析时按最长行补 `.`，宽度取最长行。
4. **生成 `.ts` 文件**：用下方模板，改 `meta` 与 `grid`。
5. **校验**：`npm run check:maps`（= validate + simulate 两段）。必须全部 ✓。
6. **修复并交付**：有 ✗ 就按报错定位格子修正后重跑；通过后报告文件名、尺寸、用了哪些机关。

## 字符表

| 字符 | 含义 | 字符 | 含义 |
| --- | --- | --- | --- |
| `#` | 实心方块（墙/地面） | `S` | 出生点（每图**恰好 1 个**） |
| `=` | 单向平台（下方可跳穿，`↓`+跳 下落） | `E` | 终点传送门（至少 1 个） |
| `-` | 装饰横木（无碰撞） | `C` | 检查点（死亡后复活于此） |
| `^` | 尖刺（触碰死亡） | `B` | 弹跳板（弹起约 7 格） |
| `~` | 岩浆（立即死亡） | `M` / `m` | 水平 / 垂直移动平台 |
| `o` | 金币 | `>` `<` | 向右 / 向左加速带 |
| `.` 或空格 | 空气 | | |

一格 = 16×16 像素。

## 物理约束（按手感换算，画图必守）

- 单跳高 ≈ **3 格**，二段跳 ≈ **5 格**；跑跳水平 ≈ **6 格**，冲刺跳 ≈ **9 格**；弹跳板 ≈ **7 格**。
- ✅ 落差 ≤ 2 格、水平间距 ≤ 5 格的路线一定过得去。
- ⚠️ 间距 > 6 格必须靠冲刺或二段跳，别放在主线必经路上。
- 角色高 18px > 格子 16px：把 `S`/`E`/`C`/`B` 放在**实心块的上一格**，角色刚好站在地面上。

## 硬性规则（validate 会查，先自查）

- 出生点 `S` 恰好 1 个；终点 `E` 至少 1 个。
- `S`/`E`/`C` 下方 3 格内必须有落脚方块（`#` `=` `B` `M` `m`）。
- `B`/`^`/`~` 下方必须是实心（`#` 或 `~`）。
- 移动平台 `M`/`m` 在仿真里按"停在中心"的静态实体处理 → 只能当**可选路线**，不能是唯一通道。
- 终点触发框高 30px：贴地跑进去必触发；高空满跳可能从门上方飞过（玩家可走回），设计时别把 `E` 悬在跳不过去的高度。
- **终点 `E` 放在贴地、路线末尾（最右一列最稳）**：仿真 bot 会用二段跳"救援"越过障碍，可能跳过中途的触发窗口；把 `E` 放最右列，让触发窗口覆盖落点区，落地即通关。
- 最后一个障碍物（尖刺/坑）之后要留足落地跑道，别让 `E` 紧贴障碍。

## 模板

```ts
import type { LevelData } from '../../core/map-format';

const level: LevelData = {
  meta: {
    id: 'my-level',          // 全局唯一，存档 key
    name: '第四关：我的关卡',
    hint: '选关界面里的一句话提示',
    theme: 'forest',         // 可选：forest | cave | sky
  },
  grid: [
    '................',
    '.....o..........',
    '.S......^^^....E',
    '################',
    '################',
  ],
};

export default level;
```

模板已通过 `check:maps`（结构 + 可通关性双 ✓）。逐格拆解：`S` 在 (1,2) 站于地面；`^^^` 是 3 格宽的尖刺（坐在地面上，跳得过去）；`E` 在最右列贴地，bot 落地即触发。照这个骨架加长、加机关即可。

## 交付

- 保存后无需改任何其他代码；刷新页面选关界面即出现新关卡，调试单关 `http://localhost:5173/?level=N`。
- 交付时说明：文件名、尺寸（行数×列数）、用到的机关、校验结果。
