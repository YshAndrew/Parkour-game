# 地图设计指南

本文件是 `parkour-map-maker` 的进阶参考：如何在满足校验的前提下，把关卡设计得有趣、有难度曲线、不踩坑。先读完 `SKILL.md` 再使用本指南。

## 设计思路：从"一句话玩法"到网格

1. 先写一句话：这一关的核心体验是什么？例如"垂直爬升、脚下是岩浆"（03）。
2. 挑 1~2 个核心机关，不要一次全塞：每关引入一个新机制 + 复习一个旧机制即可。
3. 用安全距离（见 SKILL.md 物理约束）反推网格尺寸：单跳 3 格高 / 跑跳 6 格远，路线就在这些数字上搭。
4. 先画主干路线（S → E），再补分支（金币、检查点、可选平台），最后加装饰（`-` 横木）和危险（`^`/`~`）。

## 渐进教学与难度曲线

- 新机制第一次出现时给**加宽的安全区**：比如第一个尖刺前的跳跃距离 ≤ 4 格，让玩家有余量失误。
- 难度阶梯：窄间距 → 标准 5~6 格 → 需要冲刺/二段跳的 7~9 格，逐步收紧。
- 惩罚分级：前期用金币诱惑、后期才用致命坑；检查点 `C` 放在难度陡增之前，而不是之后。
- 主线必经路线永远 ≤ 6 格间距；7 格以上只出现在"冲刺跳"教学区或可选路线。

## 摆位技巧

- `S`/`E`/`C`/`B` 一律放在实心格（`#`）的**上一格**：角色高 18px 比格高 16px，放在格中心会嵌进地面 1px，被碰撞解算挤飞。
- 尖刺 `^` 放在实心块正上方那格（例如基岩在 y=15，尖刺放 y=14 上一格即 y=13），脚下恰好坐实。
- 岩浆 `~` 铺在基岩那一格（替换 `#`），视觉上"深渊"，掉下去即死，别让它悬空（validate 会报）。
- 检查点 `C` 间距：长图每 12~20 格放一个，配合存盘点节奏。
- 弹跳板 `B` 弹高约 7 格：落地平台放在 7 格以内，弹跳后接冲刺或二段跳可以更远，但别在必经路要求。
- 移动平台 `M`/`m`：仿真按静态中心处理，只作可选路线；作主线会通不过 simulate。

## 常见失败模式与修复

| 症状 | 原因 | 修复 |
| --- | --- | --- |
| validate 报 `S 下方 3 格无落脚` | 出生点悬空 | 在 S 下方 1~3 格内放 `#` |
| validate 报 `B/^/~ 下方不是实心` | 机关悬空 | 机关正下方放 `#`（或 `~` 下叠 `#`） |
| validate 报出生点数量≠1 | 多放了 S | 只留 1 个 S |
| simulate 报"所有策略都会死"或推进 x 卡住 | 出现断层：间距 > 6 格或落差 > 2 格在必经路 | 缩小间距 / 加中间平台 / 改落差 ≤ 2 |
| simulate 一直死 | 必经路被移动平台或过窄尖刺坑堵死 | 把移动平台改成可选路，或加安全落脚 |
| 玩家跳不到 E | E 悬空或门被抬高 | E 放地面上一格；或 E 下方补平台 |
| 终点从门上方飞过 | 触发框高 30px，满跳可越过 | 门上方加顶/平台，或把 E 放贴地处 |
| simulate 报 bot 推进到 x 远大于地图宽度后死亡 | 障碍后的"救援二段跳"让 bot 跳过 E 触发窗口，从右边缘掉出 | 把 E 放在最右列贴地，触发窗口覆盖落点；或障碍后留足跑道再放 E |

## 自动生成 → 手动微调（推荐工作流）

不想从零画图时，用项目生成器出"可通关骨架"再手动打磨，兼顾效率与手感：

1. `node scripts/gen-map.mjs -d <难度> --seed <种子>` 生成骨架图（算法保证理论可通关；难度系数控制冗余，见 SKILL.md 对照表）。
2. 打开生成的 `.ts`：改 `meta`（name / hint / theme），按主题补金币串、装饰 `-`、移动平台（**只放可选路**）。
3. 想加强难度曲线：把局部坑挖宽（≤6 格）、尖刺加宽（≤4 格）——遵守 SKILL.md 物理约束。
4. 改完跑 `npm run check:maps` 确认**结构段 ✓**；simulate 段作参考（含尖刺可能报 bot 死亡，属决策局限，理论可过即可）。
5. 交付时说明：自动生成种子 + 手动改动点 + 校验结果。

- **02-oneway-and-gaps**：16 行。深坑（挖掉 y=14/15 两行即死）+ 单向平台 `=`（可下穿）+ 移动平台 `M` 当可选路，最宽一跳 5 格。
- **03-sky-tower**：25 行 × 48 列。垂直爬升：台阶逐级"高 2 格、远 2 格"，下方铺满岩浆，垂直移动平台 `m` 作辅助，3 个检查点。
- **04-lava-bounce**：18 行。岩浆铺底 + 弹跳板 `B` 作为关键跳点。

- **06-dash-canyon**：18 行。加速带 `>` 高速冲刺。
- **07-cave-hopping**：13 行 × 60 列。洞穴主题：3 格宽尖刺 + 弹跳板 + 检查点 + 金币（注意：该图 simulate 报 bot 死亡，属尖刺决策局限，结构校验通过即合格）。

## 发布前检查清单

1. 文件名两位数字编号，排序正确；`meta.id` 全局唯一。
2. `S` 恰好 1 个、`E` 至少 1 个；S/E/C 下方 3 格有落脚；B/^/~ 下方实心。
3. 主线必经路：落差 ≤ 2 格、间距 ≤ 6 格（安全标准 5 格）。
4. 移动平台只出现在可选路线。
5. `E` 贴地放在路线末尾（最右列最稳），障碍后留落地跑道。
6. 运行 `npm run check:maps`：**结构段全部 ✓**；simulate 段作参考——含尖刺的图可能报 bot 死亡（bot 决策局限，理论可过即算通过）。
7. 交付信息完整：文件名、尺寸、机关清单、校验结果。
