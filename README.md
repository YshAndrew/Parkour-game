# 像素跑酷 Pixel Parkour

一个 HTML5 像素风横版平台跑酷游戏（Phaser 3 + TypeScript + Vite）。
**地图是纯 ASCII 文本，加一张新地图 = 新建一个 .ts 文件，不用改任何其他代码。**

## 快速开始

```bash
npm install
npm run dev          # 打开 http://localhost:5173
npm run build        # 生产构建（输出到 dist/，可直接丢到任意静态服务器）
npm run check:maps   # 校验所有地图：结构 + 可通关性
```

调试单关：`http://localhost:5173/?level=2`

## 操作

| 动作 | 按键 |
| --- | --- |
| 左右移动 | `←` `→` / `A` `D` |
| 跳跃 / 二段跳 | `Space` `↑` `W` |
| 冲刺（可冲刺跳） | `Shift` `Z` |
| 下穿单向平台 | `↓` + 跳 |
| 暂停 | `Esc` |
| 原地重开 | `R` |

手感细节：土狼时间 0.09s、跳跃缓冲 0.1s、可变跳高（松键截断）、蹬墙滑行 + 蹬墙跳、冲刺带无敌帧位移、落地/蹬墙粒子与镜头轻震。

## 加一张地图（重点）

### 三步走

1. 在 `src/levels/maps/` 新建文件，例如 `04-my-level.ts`（**文件名前缀决定选关顺序**，建议两位数字编号）。
2. 照抄下面的模板，改 `meta` 和 `grid`。
3. 保存，刷新页面 —— Vite 的 `import.meta.glob` 会自动注册，选关界面立刻出现新关卡。

```ts
import type { LevelData } from '../../core/map-format';

const level: LevelData = {
  meta: {
    id: 'my-level',        // 全局唯一，存档 key，别和其他图重复
    name: '第四关：我的关卡',
    hint: '选关界面里的一句话提示',
  },
  grid: [
    '................',
    '.....o..........',
    '.S..###.....E...',
    '########^^^^^^^^',
    '################',
  ],
};

export default level;
```

### 地图字符表

| 字符 | 含义 | 字符 | 含义 |
| --- | --- | --- | --- |
| `#` | 实心方块（墙 / 地面） | `S` | 出生点（每张图**恰好 1 个**） |
| `=` | 单向平台（可从下往上跳穿，`↓`+跳 下落） | `E` | 终点传送门（至少 1 个，碰到即通关） |
| `-` | 装饰横木（无碰撞） | `C` | 检查点（死亡后从此处复活） |
| `^` | 尖刺（碰到死亡，需坐在实心块上） | `B` | 弹跳板（弹起约 7 格高） |
| `~` | 岩浆（碰到立即死亡） | `M` / `m` | 水平 / 垂直移动平台（会载着你走） |
| `o` | 金币 | `>` `<` | 向右 / 向左加速带 |
| `.` 或空格 | 空气 | | |

一格 = 16×16 像素。每行长度可以不一样，解析时会按最长行用 `.` 补齐。

### 设计尺寸参考（重要）

按当前手感参数换算出来的安全距离，照着摆就不会出现"跳不过去"的断层：

- 单跳高度 ≈ **3 格**，二段跳 ≈ **5 格**
- 跑跳水平距离 ≈ **6 格**，冲刺跳 ≈ **9 格**
- 弹跳板高度 ≈ **7 格**
- ✅ 落差 ≤ 2 格、水平间距 ≤ 5 格的路线**一定过得去**
- ⚠️ 超过 6 格的间距必须靠冲刺或二段跳，别放在主线必经路上

摆放实体的技巧：把 `S` / `E` / `C` / `B` 放在**实心块的上一格**，角色刚好站在地面上（角色高 18px 比格子高，放在正中间会有一像素嵌进地面）。

### 别忘了校验

```bash
npm run check:maps
```

两个脚本各管一件事：

- `scripts/validate-maps.mjs` —— 结构检查：出生点数量、是否有终点、`S/E/C` 是否有落脚点、`B/^/~` 下方是否实心。
- `scripts/simulate.mjs` —— **可通关性验证**：在 Node 里用与游戏完全一致的物理规则跑一个会跳/二段跳/蹬墙跳/冲刺的 bot，确认它能零死亡跑到终点。地图画错断层时它会直接指出 bot 卡在哪一格。

> 说明：`simulate.mjs` 把移动平台按"停在中心位置"的静态实体处理，所以移动平台只适合当可选路线，别设计成唯一通道。

## 项目结构

```
src/
├── core/                 纯逻辑层（不依赖 Phaser，可单独测试）
│   ├── config.ts         所有手感 / 尺寸常量（调手感只改这里）
│   ├── controls.ts       按键映射
│   ├── map-format.ts     地图格式、字符表、解析器、standPos()
│   ├── platformer.ts     平台跳跃状态机（AABB 碰撞 + 土狼时间 + 冲刺…）
│   └── save-data.ts      localStorage 存档（最佳成绩 / 解锁进度）
├── levels/
│   ├── registry.ts       ★ 地图自动注册中心（import.meta.glob）
│   └── maps/             ★ 所有地图放这里，加文件即加关卡
├── scenes/
│   ├── BootScene.ts
│   └── GameScene.ts      把逻辑关卡渲染成 Phaser 世界
├── ui/ui.ts              DOM 覆盖层：菜单 / 选关 / 暂停 / 结算 / HUD
├── style.css
└── main.ts               入口 + UI 与场景的事件桥接
```

分层原则：**玩法规则在 `core/`（纯 TS，无 Phaser 依赖），渲染在 `scenes/`，界面在 `ui/`。**
物理是自研 AABB，没有用 Arcade Physics，方便完全掌控手感。

## 已实现

- 3 张自带关卡（起步教学 → 深坑尖刺 → 天空之塔），均通过可通关性验证
- 跑酷手感：二段跳 / 冲刺 / 蹬墙跳 / 土狼时间 / 跳跃缓冲 / 可变跳高
- 单向平台、移动平台、弹跳板、加速带、尖刺、岩浆、金币、检查点
- 选关界面 + 关卡顺序解锁 + 最佳成绩与金币记录（localStorage）
- HUD（关卡名 / 金币 / 死亡数 / 计时）、暂停菜单、通关结算、死亡闪屏与粒子
- 响应式布局（FIT 缩放 + 像素化渲染），HUD 自动贴合画布

## 已知取舍

- 终点门触发框高 30px：贴地跑进去必定触发，但高空满跳可能从门上方飞过（继续向右跑回去即可）。
- 逻辑层与渲染层是"每帧同步位置"的简单关系，角色没有逐帧动画（像素方块 + 变色表示状态），要换成精灵图的话改 `GameScene.buildPlayer` 即可。
